# Inventory Mods 3.1.1

Unified compatibility release.

- Publishes Inventory Sort, Inventory Search, and Inventory Catalogue at
  version `3.1.1` across all supported Minecraft compatibility groups.
- Supports Minecraft `1.20` through `1.21.11`, plus `26.1`, `26.1.1`,
  `26.1.2`, and `26.2-pre-3`.
- Fixes a Minecraft `26.x` launch crash in Inventory Sort Core caused by the
  entity-interaction mixin targeting the older `interactAt` client method.
- No command, config, or save-data migration is required.
