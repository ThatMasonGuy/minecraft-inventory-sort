InvSort rule scopes are now world-aware.

- Player-inventory rules, container defaults, per-screen rules, and exact
  container rules now belong to the active single-player world or multiplayer
  tracked-world profile instead of being shared globally.
- Existing rule files are migrated into the new per-world layout on first use,
  preserving old container-specific rules in their original world namespaces.
- The rules screen labels now call out world-scoped player inventory and
  container defaults.
