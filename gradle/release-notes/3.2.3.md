Button placement is now coordinated through shared right-side slots.

- InvSort and InvSearch reserve ordered right-side inventory slots instead of
  using separate hard-coded heights.
- InvSearch now moves up into the first inventory button slot when InvSort is
  not installed.
- The shared Core exposes the occupied right-side button slots so companion mods
  can choose a free slot without overlapping Inventory Mods buttons.
