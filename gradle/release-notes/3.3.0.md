Inv+ bug fixes and quality-of-life improvements.

- InvCatalogue `includeInventory` now counts your carried inventory from the
  start of the session and refreshes it when you check status, generate a
  report, or stop the session.
- InvCatalogue inventory-inclusive reports now include equipped armor, offhand
  items, and any item stack currently held by the cursor.
- Stopping an InvCatalogue session now opens the newly saved report directly in
  the in-game report browser for review.
