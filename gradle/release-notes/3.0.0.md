# Inventory Mods 3.0.0

Major split-release and compatibility release.

- Inventory Sort, Inventory Search, and Inventory Catalogue are now published as separate Modrinth projects.
- Each public feature jar embeds the shared Core code, so users can install only the feature they want without downloading a separate core mod.
- Adds smoke-tested release jars for Minecraft 1.20.x and 1.21.x compatibility groups.
- Adds automated release validation that builds, checks metadata, and launches the packaged jars as standalone feature installs and all-three installs before publishing.
- Updates the public module icons, command roots, license metadata, and Modrinth publishing pipeline.
