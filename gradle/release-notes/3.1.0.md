# Inventory Mods 3.1.0

Minecraft 26.x support release.

- Adds official support for Minecraft `26.1`, `26.1.1`, `26.1.2`, and
  `26.2-pre-3`.
- Keeps Inventory Sort, Inventory Search, and Inventory Catalogue as separate
  downloads. Each mod still includes the shared Core code internally, so there
  is no separate Core mod to install.
- Requires Fabric Loader, Fabric API, and Java 25 for the selected Minecraft
  26.x version.
- No command, config, or save-data migration is required for existing users.
- Minecraft `1.20.x` and `1.21.x` players should keep using the existing
  `3.0.0` compatibility-group releases.
