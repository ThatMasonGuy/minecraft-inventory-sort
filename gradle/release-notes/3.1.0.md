# Inventory Mods 3.1.0

Minecraft 26.x support release.

- Adds official support for the smoke-tested Minecraft 26.x versions listed on
  this upload.
- Inventory Sort, Inventory Search, and Inventory Catalogue remain separate
  downloads, and each still embeds the shared Core code so no separate Core mod
  download is required.
- Existing 1.20.x and 1.21.x release lanes remain separate from this 26.x
  compatibility work.

User-visible changes to commands, config, UI, or behavior required by the 26.x
port should be added here as they are confirmed.
