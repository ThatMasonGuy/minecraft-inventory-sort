# Inventory Mods 3.1.2

Packaging cleanup release.

- Cuts the published Inventory Sort, Inventory Search, and Inventory Catalogue
  jar sizes down by roughly 5-6x in current release builds, from about
  `862-888 KB` each to about `131-156 KB` each.
- Removes duplicated unused icon assets from each package.
- Keeps each mod's own icon while avoiding repeated copies of the full icon set
  inside the embedded shared Core jar.
- Refreshes the Inventory Sort, Inventory Search, and Inventory Catalogue
  metadata descriptions shown by loaders and mod lists.
- No command, config, or save-data migration is required.
